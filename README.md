# 🏦 Bank Analytics

## 📌 Project Overview

Bank Analytics is a data analytics project focused on analyzing loan performance, banking transactions, customer behavior, and financial risk.

The project uses Excel, SQL, Power BI, and Tableau to transform banking data into KPIs, dashboards, and business insights.

## 🎯 Project Objectives

- Analyze overall loan performance
- Identify loan defaults and delinquency
- Analyze loans by branch, state, product, and customer segments
- Analyze credit and debit transactions
- Identify transaction trends and high-risk transactions
- Create interactive dashboards for business analysis

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data cleaning, analysis, Pivot Tables and charts
- **SQL** – Data querying, aggregation and KPI analysis
- **Power BI** – Interactive dashboards and visualization
- **Tableau** – Interactive dashboards and business insights

# 🔍 Key Insights

### Loan Analytics

- Business loans represented approximately **₹327M** in funded loans.
- Home loans represented approximately **₹272M**.
- Uttar Pradesh, Punjab, and Bihar were among the states with higher funded amounts.
- The analysis showed a **1.56% default rate** and **10.84% delinquency rate**.
- Customers aged **26–45** represented the highest share among the analyzed age groups.
- 36-month loans accounted for approximately **₹431.6M**, compared with approximately **₹301.1M** for 60-month loans.

### Credit & Debit Analytics

- Credit and debit transaction amounts were closely balanced.
- Branch transaction volumes were analyzed comparatively.
- Transaction methods showed relatively similar usage.
- Monthly transaction activity was analyzed to identify trends.
- More than **20,000 high-risk transactions** were identified in the analysis.
